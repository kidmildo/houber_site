## 2. 사진 넣는 방법

HTML 파일에서 아래처럼 생긴 **점선 상자 부분을 통째로** 지우고,

```html
<div class="photo-slot about__photo reveal reveal--2">
  <p class="photo-slot__text">
    <b>PHOTO</b>
    오사카 사무실 외관 또는<br>실내 워킹샷<br>(세로 4:5)
  </p>
</div>
```

다음 한 줄로 바꿔주세요.

```html
<img class="photo about__photo reveal reveal--2"
     src="assets/images/about-office.jpg"
     alt="오사카 ADERS 사무실 전경"
     width="800" height="1000" loading="lazy">
```

### 주의사항

- **일본어 페이지(`ja/index.html`)에서는 경로 앞에 `../` 를 붙여야 합니다.**
  → `src="../assets/images/about-office.jpg"`
- `class` 에 원래 붙어 있던 `about__photo`, `reveal` 등은 **그대로 유지**하세요.
  (레이아웃과 등장 애니메이션이 이 클래스에 연결되어 있습니다)
- `alt` 는 사진 설명입니다. 시각장애인용 스크린리더가 읽고, 검색에도 쓰입니다.
  장식용 사진이면 `alt=""` 로 비워두세요.
- `width` / `height` 는 실제 픽셀 크기를 적어주세요.
  브라우저가 미리 자리를 잡아 화면이 덜컹거리는 현상을 막아줍니다.
- `loading="lazy"` 는 화면에 보일 때 사진을 불러오게 해 첫 로딩을 빠르게 합니다.
  단, **첫 화면에 바로 보이는 사진에는 붙이지 마세요** (오히려 느려집니다).

## 3. 사진을 구할 수 있는 곳

배포해도 문제가 없으려면 **"상업적 이용 허용"** 이 명시된 사진이어야 합니다.

**무료**

- **Unsplash** (unsplash.com) — 상업적 이용 허용, 출처 표기 의무 없음
- **Pexels** (pexels.com) — 위와 동일
- **PAKUTASO** (pakutaso.com) — 일본 로컬 무료 스톡. 일본식 사무실·생활 컷이 많음
- **O-DAN** (o-dan.net) — 여러 무료 스톡을 한 번에 검색

**유료 (라이선스가 가장 명확)**

- Adobe Stock / Shutterstock — Standard License 로 상업적 웹 게재 가능

### 반드시 확인할 것

- ⚠️ **`Editorial use only` 표기가 있는 사진은 회사 홍보 사이트에 쓸 수 없습니다.**
- ⚠️ 사람 얼굴이 나오는 사진은 **모델 릴리즈(초상권 동의)** 포함 여부를 확인하세요.
- ⚠️ 실제 매물·매장 사진처럼 보이는 스톡 사진은 고객에게 혼동을 줄 수 있습니다.
  분위기 사진은 스톡으로 채우더라도,
  **실제 매물·매장·구성원 사진은 직접 촬영본으로 교체**하는 것을 권장합니다.

## 4. 업로드 전 최적화

사진 파일이 크면 사이트가 느려집니다. 올리기 전에 줄여주세요.

- 가로 폭을 위 표의 권장 크기 정도로 줄이기
- [squoosh.app](https://squoosh.app) 등에서 압축 (한 장당 **200KB 이하** 권장)
- 가능하면 `.webp` 형식 사용 (같은 화질에 용량이 작습니다)
